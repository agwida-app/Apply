# ردّ — رد تلقائي على تعليقات فيسبوك وإنستغرام

عندما يعلّق الزبون على منشور، يرد التطبيق على تعليقه بالرد الذي اختاره صاحب الصفحة، ويرسل له رسالة خاصة (ماسنجر / Direct). الرد والرسالة يُحددان لكل منشور على حدة.

## التشغيل محلياً

```bash
npm install
cp .env.example .env      # ثم عدّل القيم
npx prisma db push        # إنشاء قاعدة البيانات
npm run dev               # http://localhost:3000
```

- **الوضع التجريبي** (`DEMO_MODE="true"`): يظهر زر «دخول تجريبي» في صفحة الدخول، مع صفحة ومنشورات وهمية، وزر لمحاكاة تعليق زبون. هكذا يمكن تجربة كل شيء بدون تطبيق فيسبوك. **أوقفه في الإنتاج.**
- **لوحة الإدارة**: `/admin` (البريد وكلمة المرور من `ADMIN_EMAIL` و `ADMIN_PASSWORD`).

## الصفحات

| العميل `/dashboard` | الإدارة `/admin` |
|---|---|
| الرئيسية: إحصائيات، خطوات البدء، تنبيهات المشاكل | نظرة عامة: العملاء، الدخل الشهري، ردود وفشل اليوم، «يحتاج انتباهك» |
| المنشورات والردود: إضافة منشور (من القائمة أو بالرابط)، الرد العلني بعدة صيغ، الرسالة الخاصة، كلمات مفتاحية، تأخير، معاينة حية | العملاء: بحث وفلترة، الاستهلاك، الحسابات التي فيها مشاكل |
| الحسابات المربوطة: ربط/إيقاف/فصل، وتنبيه عند انتهاء الصلاحية | ملف العميل: تفعيل/تمديد الاشتراك يدوياً، تجربة مجانية، إيقاف الحساب، ملاحظات داخلية، واتساب/بريد، مراسلة، الدخول كالعميل، إعادة محاولة رد فاشل |
| سجل النشاط: كل تعليق وما حدث معه | المشاكل والتنبيهات: أخطاء الرد، انتهاء الصلاحيات، طلبات الدفع |
| الاشتراك: الاستهلاك، الدفع بالبطاقة (Stripe) أو التحويل البنكي | رسائل الدعم: الرد على العملاء |
| الدعم: مراسلة الإدارة | |

## إعداد تطبيق Meta (فيسبوك)

1. أنشئ تطبيقاً من نوع **Business** في [developers.facebook.com](https://developers.facebook.com) وضع `META_APP_ID` و `META_APP_SECRET`.
2. أضف منتج **Facebook Login for Business**، ورابط إعادة التوجيه: `https://نطاقك/api/auth/facebook/callback`.
3. أضف منتج **Webhooks**:
   - كائن **Page**: الرابط `https://نطاقك/api/webhooks/meta` و Verify Token = `META_VERIFY_TOKEN`، واشترك في الحقل `feed`.
   - كائن **Instagram**: نفس الرابط، واشترك في الحقل `comments`.
4. أضف منتج **Messenger** و **Instagram** (لإرسال الرسائل الخاصة).
5. الصلاحيات المطلوبة (تحتاج **App Review** من Meta قبل أن يستخدمها عملاء حقيقيون):
   `pages_show_list, pages_read_engagement, pages_read_user_content, pages_manage_metadata, pages_manage_engagement, pages_messaging, instagram_basic, instagram_manage_comments, instagram_manage_messages, business_management`
   - قبل الموافقة يعمل التطبيق فقط مع حسابات المطورين/المختبرين المضافين في التطبيق.
   - ستحتاج **Business Verification** وفيديو يشرح كيف يُستخدم كل إذن، وصفحة سياسة خصوصية.

> قيود فيسبوك: رسالة خاصة **واحدة** فقط لكل تعليق، وخلال **7 أيام** من التعليق. الرد يكون فقط على التعليقات الرئيسية (لا على الردود داخلها)، ونتجاهل تعليقات الصفحة نفسها لتجنب الحلقات.

## الدفع

- **Stripe** (اختياري): ضع `STRIPE_SECRET_KEY` و `STRIPE_WEBHOOK_SECRET` ومعرفات الأسعار، وسجّل Webhook على `/api/webhooks/stripe` للأحداث `checkout.session.completed`, `customer.subscription.updated`, `customer.subscription.deleted`.
- **تحويل بنكي/محفظة**: العميل يرسل رقم العملية، فيظهر طلبه في لوحة الإدارة وتفعّل اشتراكه يدوياً.
- **تجربة مجانية**: `TRIAL_DAYS` (افتراضياً 7 أيام، بحدود مخففة).
- الباقات وحدودها في `src/lib/plans.ts`.

## الردود المؤجلة (خيار «تأخير الرد»)

الردود الفورية تُنفّذ مباشرة. المؤجلة وإعادة المحاولة تحتاج تشغيل أحد الخيارين:
- `npm run worker` (عملية دائمة على السيرفر)، أو
- استدعاء `GET /api/cron/process` كل دقيقة مع الترويسة `Authorization: Bearer $CRON_SECRET`.

## النشر للإنتاج

- غيّر `provider` في `prisma/schema.prisma` إلى `postgresql` (مثلاً Supabase أو Neon) و `DATABASE_URL`.
- ولّد مفاتيح جديدة: `openssl rand -hex 32` لـ `ENCRYPTION_KEY`، وقيمة طويلة لـ `SESSION_SECRET`، وكلمة مرور قوية للإدارة.
- `DEMO_MODE="false"`.
- يعمل على Vercel أو أي سيرفر Node (يتطلب HTTPS حتى يقبل فيسبوك الـ Webhook).

## البنية التقنية

Next.js 15 (App Router) · TypeScript · Tailwind · Prisma · Meta Graph API · Stripe. توكنات فيسبوك مُشفّرة (AES-256-GCM) في قاعدة البيانات، وكل Webhook يُتحقق من توقيعه.

```
src/lib/engine.ts        محرك الرد: الفلترة، منع التكرار، الإرسال، إعادة المحاولة
src/lib/meta.ts          التعامل مع فيسبوك/إنستغرام + البيانات التجريبية
src/app/api/webhooks/    استقبال التعليقات (Meta) والمدفوعات (Stripe)
src/app/dashboard/       لوحة العميل
src/app/admin/           لوحة الإدارة
```
